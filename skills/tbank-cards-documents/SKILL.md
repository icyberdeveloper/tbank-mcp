# Карты и документы

Здесь всё только читающее. Но два тула отдают **полные платёжные и паспортные
данные** — они попадают в переписку, поэтому обращайся с ними осознанно.

## Инструменты

| Тул | Что делает |
|---|---|
| `list_cards()` | Все карты: `id`, `ucid`, счёт, тип, баланс |
| `card_limits(ucid)` | Лимиты на покупки и снятие + сколько израсходовано |
| `card_requisites(ucid, reveal)` | Держатель, срок, номер. По умолчанию маскирован |
| `card_operations(card_id, days, limit)` | Операции по ОДНОЙ карте |
| `account_requisites(account_id, currencies)` | Реквизиты для входящего перевода |
| `documents(kind, include_others)` | Паспорт, загран, права, СНИЛС, ИНН, ОСАГО, ПТС |
| `bank_documents()` | Справки банка (о движении средств и т.п.) |
| `insurance_policies()` | Страховые полисы |
| `payment_receipt(payment_id)` | PDF-чек по платежу |

## Два идентификатора карты — не путай

`list_cards()` возвращает у каждой карты **и `id`, и `ucid`**. Это разные вещи:

- **`ucid`** → `card_limits`, `card_requisites`
- **`id`** → `card_operations` (и это же значение лежит в поле `card` у операции)

Перепутаешь — тул молча вернёт данные другой карты или пустоту. Карты, привязанные
из **других банков**, помечены «внешняя» и `ucid` у них нет: лимиты и реквизиты по
ним недоступны, это нормально, не пытайся обойти.

## Уровень сессии

`card_requisites` и `documents` проверяют не только токен, но и **уровень мобильной
сессии**, а он живёт около 11 минут. Тулы поднимают его сами. Если всё же вернулось
`AccessDenied` или `SESSION_IS_ABSENT` — вызови `session_status()` и повтори один
раз; это не ошибка запроса.

## Полные реквизиты карты

```
card_requisites(ucid)                # маскировано: 5536 **** **** 1234, CVV скрыт
card_requisites(ucid, reveal=True)   # полный номер + CVV
```

`reveal=True` ставь **только если пользователь прямым текстом попросил показать
полные реквизиты** — «покажи мою карту» такой просьбой не является. Перед вызовом
предупреди, что данные окажутся в переписке. Факт раскрытия пишется в журнал
событий (сам номер — никогда).

## Документы

```
documents()                      # все
documents("паспорт")             # один вид
documents(include_others=True)   # вместе с документами родственников
```

В хранилище банка лежат **и документы родственников**, которые пользователь когда-то
вводил. По умолчанию они отфильтрованы по дате рождения владельца. Если пользователь
ищет «паспорт жены» — тогда `include_others=True`, и обязательно скажи, чей документ
показываешь.

## Реквизиты счёта — для входящих

```
account_requisites(account_id)                      # рубли
account_requisites(account_id, currencies="RUB,USD")  # блок на каждую валюту
```

Это то, что диктуют, когда деньги переводят **тебе**. Не путай с
`get_data("requisites")` — там лукап получателя в СБП по телефону, для него есть
`transfer_sbp_resolve(phone)`.

## Правила

1. **`ucid` для лимитов и реквизитов, `id` для операций.** Оба берутся из `list_cards()`.
2. **`reveal=True` — по явной просьбе и с предупреждением.**
3. **Чужие документы показывай, только если попросили,** и называй чьи.
4. **`payment_receipt` требует `payment_id`,** который есть в ответе `transfer()` и в
   `orders()`. Потом его взять негде — если чек нужен, сохраняй сразу.
5. **Не пересказывай номер карты и CVV повторно** в последующих сообщениях: чем
   меньше раз они попали в переписку, тем лучше.
